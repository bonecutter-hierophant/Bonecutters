# Architecture

This folder holds repo-level structure and diagrams that span more than one page or component.

- `project-structure.md` describes the static website layout.
- `hosted-boundary.puml` shows the intended S3/CloudFront/IAM separation from SimpleETL.
- `uml-index.puml` links the project-level PlantUML diagrams.
- `../design/frontend-design-rules.md` owns the primitive-first frontend design rules.

Page and component diagrams should live beside the code they describe.
